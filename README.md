# Industry, Innovation & Equality · ODS 5 + ODS 9

Sitio interactivo de concientización sobre los Objetivos de Desarrollo Sostenible 5 (igualdad de género) y 9 (industria, innovación e infraestructura), con enfoque en Guanajuato, México.

## Ejecutar con Streamlit

Instala las dependencias y ejecuta la aplicación:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

`app.py` integra el HTML, CSS, JavaScript y recursos locales en un componente de Streamlit. Así se conservan el diseño, las escenas 3D y los juegos sin depender de un servidor estático aparte. `index.html` y sus archivos asociados siguen siendo la fuente de la interfaz.
